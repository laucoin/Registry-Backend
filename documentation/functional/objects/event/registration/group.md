# 🤼 Group 🟣

## Definition

Cf. [Glossary](../../../../../../../../Perso/registry-documentation/glossary.md)

### Properties

* **Name**\
  The name is the human identifier for the Group. It must not be unique but it's recommended to create the most explicit name.
* **Hidden**\
  A Group can be hide and restore.

## Features

### As a User

* I can consult the Groups (with search, sort, etc.)
* I can add Participants or Guest to a Group
* I can remove Participants or Guest from a Group
* I can create a Group
* I can edit a Group
* I can hide a Group
* I can restore a Group
* I can delete a Group

{% hint style="info" %}
Bear in mind that this type of data is often created all at once (or at least a lot at once). The UX must be geared to this context.
{% endhint %}

## Constraints

* I can sort Groups by name.
* I can search Groups by name.
