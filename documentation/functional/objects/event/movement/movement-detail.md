# 🔍 Movement Detail 🔵

## Definition

Cf. [Glossary](../../../../../../../../Perso/registry-documentation/glossary.md)

### Properties

* **Participant**\
  Participant linked to the Movement Detail. Without it the Movement detail is useless.
* **Vehicle**\
  Vehicle linked to the Movement Detail.
* **Comments**\
  Linked to the Vehicle if present

Refer the [Movement's features](./#features), because Movement Detail is closely linked to a Movement.
