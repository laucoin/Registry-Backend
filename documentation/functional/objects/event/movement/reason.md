# 💬 Reason 🟠

## Definition

Cf. [Glossary](../../../../../../../../Perso/registry-documentation/glossary.md)

### Properties

* **Name**\
  The name is the human identifier for the Reason. It must not be unique but it's recommended to create the most
  explicit name.
* **Require Activity**\
  You can force activity selection in the departure or arrival form depending the reason.
* **Target**\
  Proposed for departure, arrival or both
* **Hidden**\
  A movement Reason can be hide and restore.

## Features

### As a User

* I can consult the Reasons (with search, sort, etc.)
* I can create a Reason
* I can edit a Reason
* I can hide a Reason
* I can restore a Reason
* I can delete a Reason

## Constraints

### As a User

* I can sort Reasons by name.
* I can search Reason by name.
