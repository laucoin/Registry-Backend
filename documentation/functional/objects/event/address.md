# 🗺️ Address 🔴

## Definition

Cf. [Glossary](../../../../../../../Perso/registry-documentation/glossary.md)

### Properties

* **Number**\
  Number of the road, street, etc.
* **Street**\
  Street name or named place
* **Complementary information**\
  Complementary like building number, entrance, etc.
* **Zip code**\
  Postal code of the city
* **City**\
  City name
* **Country**\
  Name of country
* **Province**\
  Depending of the country

Refer the [Event's features](./#features), because Address is closely linked to an Event.
