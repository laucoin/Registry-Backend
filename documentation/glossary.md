# 📖 Glossary

**Activity:** An activity is a recurent thing that a person or group does or has done.

**Activity Communication:** An activity communication is a communication exchange between, the Event organizer, director or other participant and an activity instance.

**Address:** An address can be consider as an optional object. Indeed, his presence was only justify to add more precision to identify an Event.

**Event:** An event can be compared to a gathering of people or a group of people on a particular occasion. It may last a certain amount of time. An event is the "brain" of Registry. Without it, the application is useless.

**Encode:** Process of modifying one value (text, file, etc.) for another. In Registry, we use the term encoding to designate symmetrical or asymmetrical encryption, i.e. when a text is encoded in such a way that only authorized persons can decrypt it.

**Fire risk:** In France, Forest access is limited by the fire risk. We store it to inform event's participant about the risk.&#x20;

**Guest:** Guest is an unexpected Participant.

**Hash:** A hash function is an algorithm for modifying a text (called a message) into a fixed-length value (called a hash). A hash cannot be de-hashed to find the original message.

**Movement:** A movement is one of Registry base. Indeed, a movement contains one or more Movement Detail.

**Movement Detail:** A Movement Detail is a part of a Movement to give specificities about 1 participant movement (Example: Vehicle). That allow movement to log participants entry or exit with a vehicle.

**Option:** Options should be considered as feature flipping. Depending of your Event, you may need some feature or not. Following features are defined as option an can be enable or disabled for a specific Event.

**Organization:** An Organization is a Registry B2B customer. For example, Registry's original client was the “Scouts et Guides de France” association. An Organization is the highest hierarchy level of the application. This entity can define many management rules about sub level features and options.

**Participant:** A Participant is a natural person who takes part in one or more events. A User is a Participant, but the reverse is not always true.

**Presence Report:** Contains important information about the entry or exit of participants within a monitored perimeter. Initially designed to count people present in a perimeter (count reset every night).

**Profile:** A Profile define User or Structure Role for an Event or a Registration

**Group:** A Group is a sub entity of Registration, it is a participants' Group. It is an optionnel level to make easier the participants manipulation.

**Phone Communication:** A Phone Communication is a communication exchange between, the Event organizer or director and another party.

**Registration:** A Registration is a bundle of Event's Participant. It can be the result of a registration request via the ticketing system, or it can be created by hand.

**Reason:** A Reason is a description for a movement for an arrival and/or departure.

**Role:** A role enabling or disabling operations on an event and related objects. Event's roles are defined with a business name by each organization during the onboarding (Example : Scout Event administrator can be a role). Behind each role there are [permissions](glossary.md#permissions).

**Service Account:** A service account has the same properties as a user, but is not a physical person. It can access events, but cannot be considered a participant.

**Smoke Report:** A smoke reporting contains some details about a fire smoke. That informations are useful to report the smoke to firemen.

**Ticketing:** The ticketing represent the exposed Event and allow User to make a registration demand.

**User:** A User is a natural person who can connect via an Organization's identity provider system.

**Structure:** A Structure is a recursive bundle of Users with a right level.

**Vehicle:** A Vehicle a thing used for transporting people or goods, especially on land, such as a car, lorry, or cart. It can be a car, boat or something else.
